# Lydeffekter

Læg lydfiler ind i denne mappe for at få lydeffekter i spillet. Filerne skal hedde:

| Fil | Afspilles når |
|---|---|
| `laage.mp3` / `.ogg` / `.wav` | en låge åbnes |
| `god.mp3` / `.ogg` / `.wav` | du finder en god juleting |
| `kat.mp3` / `.ogg` / `.wav` | en ond kat dukker op |
| `sejr.mp3` / `.ogg` / `.wav` | du vinder (HURRAAA) |
| `tab.mp3` / `.ogg` / `.wav` | du taber (suk hulk) |

Spillet prøver `.mp3` først, derefter `.ogg`, derefter `.wav`. Mangler en fil, springes den bare over.

Tip: Opret filerne direkte på GitHub via **Add file → Create new file** og skriv f.eks. `lyd/kat.mp3` — så laver GitHub mappen automatisk, når du uploader lyden.
